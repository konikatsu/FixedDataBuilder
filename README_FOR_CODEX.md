# 開発・公開時のルール

- Windows Forms / net8.0-windows / Windows x64を対象とする。
- 配布はframework-dependentのフォルダーZIP。ランタイムは同梱しない。
- 製品・自動テスト・GUIヘルパーの起動は利用者が行う。ビルド・静的確認・パッケージ作成は実施可能。
- 起動確認したEXE・DLL・ZIPを再ビルドせず公開する。未実行の試験を成功と記載しない。
- READMEは使い方を中心に簡潔にする。画像を捏造しない。
- 実データ・認証情報・私有レビュー資料をコミットしない。明示したファイルだけをstageする。
- GitHubへの送信は利用者が許可した範囲で行う。
