# 入力・出力を上下に並べる架空サンプル（v0.1.75）

4つの `comparison-*-definition.csv` / `comparison-*-data-utf8.csv` は動作を確かめるための架空のデータです。どちらも可変長CSV・UTF-8・ヘッダーなしとして開きます。

1. メイン画面で `comparison-output-definition.csv` と `comparison-output-data-utf8.csv` を開き、「入力・出力を並べて表示...」を押します。
2. 下段に出力3件の一覧が表示されます。
3. 上段の「入力を開く…」で `comparison-input-definition.csv` と `comparison-input-data-utf8.csv` を読み込みます。形式はCSV（ヘッダーなし）、定義は自動判別またはUTF-8、データ文字コードはUTF-8です。
4. 上段に入力3件の一覧が表示されます。入力のカラムNo.1と、出力のカラムNo.4が管理番号なので、それぞれの表を横スクロールして目で見比べます。入力1行目の `0001` は出力2行目にあります。
5. 「入力・出力の上下を入れ替え」で上に出力、下に入力を表示できます。各表の選択・スクロール位置は保持します。「空白を表示」は各側で切り替えられます。

マッピングや「行の組を確定」の操作はありません。一致・不一致は人が判断します。入力だけにある `0004`、出力だけにある `0003` も一覧に残ります。元ファイルとメイン画面の編集値は書き換えません。

このサンプルは実装と目視確認のために用意したもので、こちらでは製品・自動テストを実行していません。
