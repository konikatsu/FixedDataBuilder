# 入力・出力比較の架空サンプル

4つの `comparison-*-definition.csv` / `comparison-*-data-utf8.csv` は動作を確かめるための架空のデータです。どちらも可変長CSV・UTF-8・ヘッダーなしとして開きます。

1. メイン画面で `comparison-output-definition.csv` と `comparison-output-data-utf8.csv` を開き、「入力と出力を比較...」を選びます。
2. 比較画面で `comparison-input-definition.csv` と `comparison-input-data-utf8.csv` を読み込みます。
3. 入力1行目のID `0001` は出力2行目に対応します。両側の行番号は別々に選べます。キーを使う場合は、入力No.1と出力No.4を指定します。入力にだけある `0004`、出力にだけある `0003` を対応済みの行へ詰めないことを確認できます。
4. 出力No.1は固定値 `FIXED`、No.2は入力No.2、No.3は入力No.4→No.5の順の結合、No.4は入力No.1、No.5は入力No.3の文字を1起点・開始2・長さ4で切り取る設定にします。

コメントから見つけた入力元は候補です。切り取りや結合の意味は説明文から自動実行せず、設定画面で確定します。「入力元との一致」と「設定した式の期待値との一致」は区別します。どちらも業務上の合否を自動で保証するものではありません。

このサンプルは実装と目視確認のために用意したもので、こちらでは製品・自動テストを実行していません。
